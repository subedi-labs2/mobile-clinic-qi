# 04 — Resource Directory: Chantilly / Fairfax County, VA

> **Last verified:** 2026-11-05 (online sources, listed per entry). Phone numbers, hours, and eligibility change. **Call each resource to confirm before go-live, then re-verify quarterly.** Record the verification date in the right column.

> Fairfax County's **Coordinated Services Planning (CSP) line, 703-222-0880**, is the single front door for most county human services and can help when you don't know where to start.
