# Templates

| File | Use |
|---|---|
| [screening-form.md](screening-form.md) | Printable paper screening form with a staff scoring box |
| [pdsa-worksheet.md](pdsa-worksheet.md) | One per PDSA cycle |
| [../data/templates/screening_log.csv](../data/templates/screening_log.csv) | Blank screening log, one row per adult visit |
| [../data/templates/referral_log.csv](../data/templates/referral_log.csv) | Blank referral log, one row per referral offered |

Word/PDF versions of the forms are generated in `dist/` by `scripts/build_docs.sh`.

**Real data** goes in `data/real/`, which is git-ignored. **Never commit real patient data.** See [08](../docs/08-ethics-privacy.md).
